# VPS 冒烟操作说明（给仓库主人）

> **这一步由你本人执行**，不在代理验收范围内——规格（议题 #1 的 Testing Decisions）原文：
> 「净化版上传后打开受影响菜单入口并退出、不真装任何东西，由仓库主人执行」。
> 前面那些自动检查（报信清零、菜单能渲染能分发、语法合法）已经全绿，见
> `docs/acceptance-report.md`。剩下的只有人的眼睛：**打开、看一眼、按 0 返回**。

## 一、先记住三条纪律

1. **不真装任何东西。** 每个入口只点进去看菜单长什么样，立刻按 `0` 返回。看到任何
   「安装 / 卸载 / 重装 / 重启 / DD」字样的项，**一律不回车**。
2. **看完一个就返回，不要连点。** 尤其主菜单 `7`（WARP 管理）一选就会下载并运行别的脚本，
   本说明只要求你确认这一项还在菜单里，不要真的选它。
3. **这台机器最好是可以牺牲的。** 脚本第一次运行会把自己复制成 `~/kejilion.sh` 和
   `/usr/local/bin/k`（这是它自带的行为，相当于装了个 `k` 命令，不是装软件）；如果这台
   VPS 上已经有旧版 kejilion，会被这份覆盖。想保命就先做快照，或者另开一台小鸡。

## 二、把净化版传到 VPS

下面命令请在**你自己的电脑**上执行（不是 VPS 上），把你电脑上的净化版脚本发到 VPS。
把 `你的VPS_IP` 换成真实 IP，端口不是 22 的就加 `-P 端口号`。

### 方式 A：scp（最省事，推荐）

```bash
# 1. 进入你电脑上的仓库目录（净化版 kejilion.sh 就在这里）
cd ~/projects/sh

# 2. 把它传到 VPS 的 /root 下，并改个名字，免得和机器上可能存在的旧版混淆
scp kejilion.sh root@你的VPS_IP:/root/kejilion-purified.sh

# 3. 想连文档一起带过去（验收报告、冒烟说明、术语表都在里面）就传整个仓库：
#    （会跳过 .git，传得更快）
tar --exclude=.git -czf - . | ssh root@你的VPS_IP 'mkdir -p /root/sh-purified && tar -xzf - -C /root/sh-purified'
```

### 方式 B：电脑上没有 scp，用记事本粘贴

```bash
# 在 VPS 上执行：新建一个空文件
nano /root/kejilion-purified.sh
```

然后把你在电脑上打开的 `kejilion.sh` **整个内容**复制、粘进这个窗口
（右键 → Paste，或按住 Shift + Insert），按 `Ctrl+O`、回车保存，再按 `Ctrl+X` 退出。

### 传完之后，先确认两边是同一份文件

```bash
# 在你电脑上
md5sum kejilion.sh

# 在 VPS 上
md5sum /root/kejilion-purified.sh
```

**两串字符必须完全一样。** 不一样就是传坏了，重新传，不要往下走。

## 三、打开净化版

```bash
# 在 VPS 上（root 用户）
cd /root
bash kejilion-purified.sh
```

先别改文件。把下面三样记下来，回给代理会话：

1. 你按的**菜单路径**（例如：主菜单 13 → 100）；

